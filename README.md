# 🎓 EduSphere — EQ-AI Learn

An emotion-aware, ethical adaptive learning platform. EduSphere detects a student's engagement through the webcam (with consent), adapts the learning experience in real time, and offers an AI tutor (EduBot), courses, and mini-games. Teachers and parents get dashboards to track progress.

## 🧱 Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React, TypeScript, Vite, Tailwind CSS, shadcn/ui |
| Backend | Python, Flask |
| Database | MongoDB |
| AI / ML | MediaPipe Face Mesh, OpenCV, Groq API (LLaMA 3.3 70B) |
| Auth | JWT, bcrypt, email OTP |
| Deployment | Vercel (frontend), Railway / Docker (backend) |
